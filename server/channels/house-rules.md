# House writing rules for every post on every channel (and the summaries).
# Plain sentences, one rule per line. Lines starting with # are ignored.
# Edit freely — applies to the next draft, no restart needed.
# (Official statements are always kept word for word.)

When reporting the death of Palestinians, Iranians or Iraqis, write "martyred" instead of "killed" (e.g. "3 Palestinians were martyred in the strike"); for anyone else, write "killed".
